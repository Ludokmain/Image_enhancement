- **Python 3.x.x** <!-- TODO: your version, from `python --version` -->
- Dependencies (listed in `requirements.txt`): `opencv-python`, `numpy`, `scikit-image`, `matplotlib`

## Installation

From the HW1 folder of the repository:

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run the experiment

```bash
python project.py
```

This single command runs the complete pipeline: it reads the images in `original/`, creates the degraded versions, applies all the methods, saves the side-by-side comparisons and computes the metrics (`results/metrics.csv`, `results/metrics_table.tex`, `results/metrics_tables.pdf`).

At the end the comparisons are shown in OpenCV windows: **press any key** to close them and end the script. All files are already saved before the windows open.
